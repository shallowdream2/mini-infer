# infer-summarize

在 `mini-infer` 仓库里，`infer-summarize` 以 Claude 侧同名 skill、checklist 和 template 为权威来源。

## 必读

1. `CLAUDE.md`
2. `.claude/skills/infer-summarize/SKILL.md`
3. `.claude/skills/infer-summarize/CHECKLIST.md`
4. `.claude/skills/infer-summarize/TEMPLATE.md`

## 执行原则

- 对照验收标准、引用真实实验记录、记录失败点和下一步计划时，按 Claude 版本原样执行
- 完成后动作和落盘位置也按 Claude 版本执行
- 如果 Codex 侧旧版 summarize 说明更简化，以 Claude 文件为准
