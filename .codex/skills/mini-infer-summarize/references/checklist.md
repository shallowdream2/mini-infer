# Mini Infer Summarize Checklist

## Completeness

- [ ] Background and goal are explicit
- [ ] Completed work names concrete files or outputs
- [ ] Key achievements are backed by real data or clear functional milestones

## Acceptance criteria review

- [ ] Acceptance criteria were found from the plan or route map
- [ ] Each criterion is marked as achieved, partially achieved, or not achieved
- [ ] Unmet items include a reason and follow-up

## Data integrity

- [ ] Performance numbers come from experiment records
- [ ] No remembered or estimated numbers are presented as measured facts

## Failures and risks

- [ ] Unexpected issues are recorded
- [ ] Remaining risks are explicit

## Next steps

- [ ] Next steps name concrete files, features, or validation work
- [ ] No empty "continue optimizing" style placeholders
