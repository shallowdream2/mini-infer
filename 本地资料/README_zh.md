# 本地资料索引

这个文件用于说明 `本地资料/` 目录的用途和当前结构，避免把历史草稿或旧版模板 README 误当成当前项目的正式说明。

## 当前定位

- `本地资料/` 只放个人研究、环境记录、路线图、总结和博客草稿
- 项目的正式入口仍然是仓库根目录下的 `README.md` 和 `CLAUDE.md`
- 当前默认环境前提：已经位于 Ubuntu 24.04 项目终端；真实 benchmark 依赖 CUDA GPU

## 目录说明

- `环境配置/`：Ubuntu 环境、Claude 配置和项目工作流说明
- `Claude计划/`：长期路线图和阶段规划
- `里程碑总结/`：阶段性完成情况、复盘和下一步
- `知识专题/`：围绕 PagedAttention、KV Cache、调度等主题的沉淀
- `实验记录/`：命令、指标、结论和实验现象
- `博客草稿/`：面向发布的技术文章草稿

## 使用边界

- 这里的内容以个人长期记录为主，不要求像正式文档一样稳定
- 如果项目目标、环境边界或 benchmark 口径发生变化，应先同步根目录 `README.md`
- 与用户级 Claude Code 配置有关的说明，统一收敛到 `环境配置/` 目录维护
