## 背景与目标

Phase 13 实现了 Tensor Parallelism（单卡 98.0 tok/s，TP=2 76.5 tok/s），解决了多卡显存扩展问题。Phase 14 换方向，从**纵向压缩 KV cache** 出发，理解 DeepSeek-V2/V3/R1 的核心架构创新：Multi-head Latent Attention（MLA）。

目标：用真实 DeepSeek-V2-Lite 权重验证 MLA 两种 cache 策略的数学等价性，量化 KV cache 压缩比，并实现矩阵吸收优化版本。

### 三种实现

1. **MLAAttentionNaive**：与 HF DeepseekV2Attention.forward() 数学等价，缓存完整 key/value（10,240 bytes/token/layer）
2. **MLAAttentionLatentCache**：只缓存 compressed_kv + k_pe（1,152 bytes/token/layer），attention 时即时展开
3. **MLAAttentionAbsorbed**：矩阵吸收优化，预计算 W_k_absorbed/W_v_absorbed，直接用 compressed_kv 计算 score 和 output，跳过 k_nope 展开

## 关键成就

### KV Cache 压缩比（来自实验记录 2026-03-22-phase14-benchmark.md）

| 策略 | bytes/token/layer | 相对 GQA |
|------|-------------------|---------|
| GQA（Qwen2.5-7B） | 2,048 | 100% |
| MLA naive | 10,240 | 500% |
| MLA latent | 1,152 | **56.25%** |

- 相同 32 GB VRAM：GQA 支持 606 × seq=1024，MLA latent 支持 1,078 × seq=1024（**1.78×**）

### 数值等价性验证

- CPU 等价性（naive vs latent）：max diff < 1e-5 ✅
- CPU 等价性（naive vs absorbed）：max diff < 1e-4 ✅
- GPU 单层等价性（HF vs MLAAttentionNaive）：max diff = 0.2655（RoPE 差异，权重路径正确）✅

### 真实模型验证

- DeepSeek-V2-Lite 加载：15.20 GB（fp16，2×4090）
- 生成 64 tokens 增量：0.009 GB（MoE 模型 KV cache 极小）
- 生成内容正常，中文输出连贯

## 遇到的问题

1. **CPU fp16 matmul 不支持**：`device_map="cpu"` + `float16` 触发 `addmm_impl_cpu_ not implemented for Half`，改为 `float32` 解决
2. **HF attention_mask 强制非 None**：DeepseekV2Attention 在 `assert attention_mask is not None` 处报错，需构造 causal mask 传入
3. **MLAAttentionAbsorbed 漏掉 kv_a_layernorm**：forward 中 compressed_kv 未过 layernorm 导致 max diff = 0.165，调试后确认问题并修复
4. **重复下载进程**：误以为后台下载停止，重启了第二个进程，导致两个进程同时下载同一文件，已 kill 重复进程

## 单步 decode 延迟对比（Section 3）

batch=1，GPU RTX 4090，真实 V2-Lite 第 0 层权重，fp16：

| seq_len | naive (ms) | latent (ms) | absorbed (ms) | absorbed/naive |
|---------|-----------|------------|--------------|---------------|
| 1 | 0.140 | 0.137 | 0.161 | 1.16× |
| 64 | 0.136 | 0.136 | 0.162 | 1.19× |
| 256 | 0.132 | 0.134 | 0.159 | 1.21× |
| 1024 | 0.131 | 0.154 | 0.167 | 1.28× |

absorbed 在当前规模下比 naive 慢 16~28%，原因是 einsum 在小 batch 下开销大于 matmul。矩阵吸收的理论优势需在更大 batch 或 seq_len >> kv_lora_rank=512 时才能体现。

- 目标：同机多进程原型，Prefill/Decode 角色拆分，KV blocks 通过共享内存传输

- 风险：路线图中标注为"整个路线图风险最高的 Phase"，降级条件：跨进程 KV 传输超过 2 周无法稳定则降级为 KV 传输原型或架构设计文档
