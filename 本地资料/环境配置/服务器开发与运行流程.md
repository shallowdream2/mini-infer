# Ubuntu 项目开发与运行流程

这个文件用于记录 mini-infer 当前默认的项目工作流。环境已经按 `AI-Infra学习之旅-服务器环境配置.md` 配置完成，当前开发直接复用现有 `ai-infra` 环境，不默认重新创建环境。

## 基本事实

- 当前默认工作目录：mini-infer 项目根目录
- 主开发环境：Ubuntu 24.04 LTS
- Shell：bash
- Python：3.10+
- 目标 GPU：2 × RTX 4090
- 默认 Conda 环境：`ai-infra`

## 推荐工作流

1. 进入项目目录并激活现有环境
2. 先检查 `python --version`、`nvidia-smi`
3. 先跑最小相关测试，再做真实模型运行
4. benchmark 和性能结论只基于 Ubuntu + CUDA 实测结果

## 最低检查项

```bash
conda activate ai-infra
pwd
python --version
nvidia-smi
```

如果当前会话没有 GPU 或没有 CUDA 驱动，就只做骨架开发、单元测试和 dry-run 验证。

## 日常命令

### 开发与测试

```bash
conda activate ai-infra
python -m pip install -e ".[dev]"
python -m pytest tests/test_smoke.py tests/test_scheduler.py tests/test_kv_cache.py
```

### HuggingFace baseline benchmark

```bash
conda activate ai-infra
python benchmarks/benchmark_hf.py --model Qwen/Qwen2.5-7B-Instruct --batch-size 1 --max-new-tokens 32
```

### mini-infer 当前实现 benchmark

```bash
conda activate ai-infra
python benchmarks/benchmark_mini.py --model Qwen/Qwen2.5-7B-Instruct --batch-size 1 --max-new-tokens 32
```

## 约束

- 不默认新建环境；只有环境确实损坏或用户明确要求隔离时才重建
- 不要在没有 Ubuntu GPU 实测的情况下写性能收益
- 如果缺少模型权重、CUDA 或 GPU，必须明确说明验证边界
- 文档里的“服务器”表述，除非特指历史背景，否则统一理解为当前这台 Ubuntu 实机环境
