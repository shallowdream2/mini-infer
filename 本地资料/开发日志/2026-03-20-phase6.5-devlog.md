## Step 1：实现 mini_infer/triton_attn.py

### 设计决策

- Grid = (batch, num_q_heads)：每个 program 处理一个 (batch_idx, q_head_idx) 对
- GQA 映射：`kv_head_idx = q_head_idx * num_kv_heads // num_q_heads`
- BLOCK_N=64，HEAD_DIM=128（constexpr）
- Online softmax 状态：m_i `[1]`，l_i `[1]`，acc `[HEAD_DIM]`

### 遇到的编译报错（核心坑点）

初版代码：
```python
m_i = tl.full([1], -1e38, dtype=tl.float32)
block_max = tl.max(scores, axis=0)      # 返回 scalar（0维，无 layout encoding）
m_new = tl.maximum(m_i, block_max)      # 报错！
```

错误信息：
```
RuntimeError: PassManager::run failed
'triton_gpu.cmpf' op requires the same encoding for all operands and results
```

根因：`tl.full([1], ...)` 产生 blocked encoding，`tl.max(..., axis=0)` 返回无 layout 的 scalar，两者 encoding 不兼容。

**修复方案**：用 `scores[None, :]` 升维到 `[1, BLOCK_N]`，再 `tl.max(..., axis=1)` 规约，结果保持 `[1]` blocked encoding：
```python
block_max = tl.max(scores[None, :], axis=1)   # [1]，encoding 与 m_i 一致
m_new = tl.maximum(m_i, block_max)            # ✅
```
同理修复 `l_i` 的更新（`tl.sum(exp_scores[None, :], axis=1)`）。

### 验证通过

```
python -c "from mini_infer.triton_attn import triton_decode_attention; print('import OK')"
```

## 关键决策记录

| 决策 | 选择 | 原因 |
|------|------|------|
| BLOCK_N | 64 | 16 KB K + 16 KB V per block，适配 SM L1 cache；128-byte cache line 对齐 |
| HEAD_DIM | 128 constexpr | Qwen2.5-7B 固定参数，编译期固定可优化寄存器分配 |
| GQA 处理 | kv_head_idx = q_head_idx * num_kv_heads // num_q_heads | 简单整除映射，每个 program 独立处理，无需跨 program 通信 |
| causal mask | 不需要 | decode 时 KV cache 只存历史 token，query 天然只 attend 历史，无需显式 causal mask |
| dense KV only | 不接 block_table | Phase 6.5 目标是实验学习，不替换 flash_attn；block_table 版本是未来扩展方向 |
