## 项目题目

基于 PagedAttention 的高性能大模型推理引擎

## 当前状态

- Phase 1-12 已完成：单卡主链路、Paged KV Cache、Continuous Batching、双卡测量、True PagedAttention、Triton kernel、Preemption、Chat Completions 子集兼容 HTTP API、Chunked Prefill、Prefix Caching、Speculative Decoding、CUDA Graph
- Phase 12.5-15 仍处于未来规划阶段，尚未开始实现
- 当前代码主入口和对外说明以仓库根目录 `README.md` 为准；带日期的开发日志、里程碑总结和实验记录默认视为历史快照

## 当前环境前提

- 当前默认已经位于 Ubuntu 24.04 项目环境内
- 真实运行和 benchmark 目标环境是 2 × RTX 4090
- 没有 Ubuntu GPU 实测时，不给性能结论

## 最终目标

在单机双 `RTX 4090` 环境下，围绕 `Qwen2.5` 这类 `decoder-only` 大模型，持续构建和验证一个具备系统层与内核层代表性能力的推理系统学习项目。

当前已完成的主线目标包括：

- `Paged KV Cache`、`Prefill / Decode` 分离、`Continuous Batching`
- `True PagedAttention` 与 Triton decode attention kernel
- Preemption + Priority Scheduling
- 双卡 Replica / Pipeline Parallel 测量
- Chat Completions 子集兼容 HTTP 服务
- Chunked Prefill、Prefix Caching、Speculative Decoding、CUDA Graph

未来扩展目标见 `Claude计划/00-长期路线图.md` 中的 Phase 12.5-15。

## 已完成的核心能力

- 真实可跑的 `LLMEngine.generate()`
- `Paged KV Cache` + `Block Table`

- Prefix Caching 与共享前缀复用
