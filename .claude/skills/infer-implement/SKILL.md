# infer-implement

这个文件用于在当前项目中实现具体功能或修改现有代码。

把附加文本视为当前实现任务，并遵守这些要求：

- 先读相关文件，再改代码
- 只改与当前任务直接相关的文件
- 优先最小可运行实现
- 完成后说明改了什么、为什么这样改、如何验证、还缺什么
- 如果环境不满足验证条件，明确指出，不得伪造结果
