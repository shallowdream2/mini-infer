# infer-archive 检查清单

这个文件列出每个阶段结束时必须核查的产出项，用于 infer-archive 执行时逐项对照。

## 必须存在的产出（每阶段）

### 里程碑总结（来自 infer-summarize）
- [ ] `本地资料/里程碑总结/` 下有本阶段的总结文件
- [ ] 文件包含：目标、完成内容、关键成就、问题、当前状态、下一步

### 实验记录（来自 infer-benchmark）
- [ ] `本地资料/实验记录/` 下有本阶段的 benchmark 文件
- [ ] 文件包含：环境、workload、结果数据、分析、结论

### 博客草稿（来自 infer-blog）
- [ ] `本地资料/博客草稿/` 下有本阶段草稿，或归档报告中明确记录了跨阶段合并写作计划
- [ ] 如果本阶段未单独成文，已说明会合并到哪个主题/哪些阶段，且 defer 原因不是“还没来得及”

### 开发日志（infer-archive 补写）
- [ ] `本地资料/开发日志/` 下有本阶段的日志文件
- [ ] 记录了：做了什么、卡在哪里、怎么解决的、关键决策

### 知识笔记（infer-archive 补写）
- [ ] `本地资料/知识笔记/` 下有本阶段涉及的核心概念笔记
- [ ] 是自己的理解，不是复制粘贴文档

### 知识专题（infer-archive 补写）
- [ ] `本地资料/知识专题/` 下有至少一篇本阶段主题的深度文档
- [ ] 使用知识专题模板，覆盖原理、实现、取舍和常见误区

### Claude 计划更新（有变更时）
- [ ] `本地资料/Claude计划/` 下的长期路线图已反映本阶段结果
- [ ] 如有范围变更或新计划，已记录

### 环境配置（有新配置时）
- [ ] `本地资料/环境配置/` 下记录了本阶段新增的环境依赖或配置步骤

### README 同步（每阶段必查）
- [ ] `README.md` 中"当前状态"已反映本阶段完成情况，不再说"骨架阶段"等过期描述
- [ ] 新增的模块、benchmark 命令、测试命令已更新到 README 对应章节

### benchmark 脚本基础验证（每阶段必查）
- [ ] 本阶段新增的 benchmark / profiling 脚本：在 dry_run 或无 GPU 环境下能完整构造 EngineConfig（防止字段名拼写错误等低级 bug 只能在 GPU 运行时才暴露）
- [ ] 验证方法：`python -c "from mini_infer.config import EngineConfig; <按脚本里的参数构造>"` 不报 TypeError

### skills/README.md 同步（每阶段必查）
- [ ] `.claude/skills/README.md` 中本阶段的进度表已更新为全部 ✓（与 CLAUDE.md 保持一致）
