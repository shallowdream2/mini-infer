# infer-summarize 检查清单

这个文件列出每次阶段总结必须满足的质量要求，用于完成后逐项对照。

## 内容完整性

- [ ] 背景与目标：说明本阶段为什么做，承接上一阶段的哪个发现或结论
- [ ] 已完成内容：具体到文件级别的产出（新增 / 修改了哪些文件）
- [ ] 关键成就：有数据支撑的性能结果或功能里程碑，不是泛泛描述

## 验收标准对照（必须逐条）

- [ ] 从 infer-plan 输出或路线图中找到本阶段验收标准列表
- [ ] 每条标准注明"达成 / 未达成 / 部分达成"，不得写"总体完成"
- [ ] 有未达成项时，写明原因和后续处理方式

## 数据可信度

- [ ] 性能数字来自 `本地资料/实验记录/` 中本阶段的 benchmark 文件
- [ ] 没有凭记忆写入的性能数字

## 失败点记录

- [ ] 如果有验收标准未达成，写出来（不美化）
- [ ] 如果有预期外的技术问题，写出来（含根因和解决方式）

## 下一步计划

- [ ] 下一步计划引用路线图中的具体阶段内容
- [ ] 不写"继续优化"等空话，必须有具体的文件或功能点
