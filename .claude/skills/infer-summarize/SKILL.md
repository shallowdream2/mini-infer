# infer-summarize

这个文件用于生成当前进度总结、阶段复盘和下一步计划。

把附加文本视为总结范围，并按以下结构整理：

- 背景与目标
- 已完成内容
- 关键成就
- 遇到的问题
- 当前状态
- 下一步计划

如果用户要求落盘，默认写入 `本地资料/里程碑总结/` 或 `本地资料/Claude计划/`。
需要结构模板时，优先参考同目录下的 `TEMPLATE.md`。

## 质量门槛（必须满足）

1. **对照验收标准**：必须逐条列出本阶段的验收标准（优先在当前对话中找 infer-plan 输出；若已 /clear，从 `本地资料/Claude计划/00-长期路线图.md` 中本阶段的"验收标准"章节获取），说明每条是"达成 / 未达成 / 部分达成"，不得只写"总体完成"
2. **引用真实数据**：性能数字必须来自 `本地资料/实验记录/` 中本阶段的 benchmark 文件，禁止凭记忆引用
3. **有失败点**：如果有验收标准未达成或出现预期外的问题，必须写出来，不得美化总结
4. **下一步计划具体**：不得写"继续优化"之类的空话，必须引用路线图中的具体下一步内容

## 完成后

在 `CLAUDE.md` 的当前阶段进度表中将 `infer-summarize` 步骤标为 ✓。
